# Índice de skills

Mapa das skills do projeto. Use para escolher o que carregar antes de trabalhar; ele não substitui as skills, só aponta o caminho. Leia o `AGENT.md` da raiz antes.

| Tarefa | Skill | Caminho |
| --- | --- | --- |
| Criar, revisar ou reorganizar uma skill | `skill-creator` | `skills/skill-creator/SKILL.md` |
| Auditar, criar ou melhorar cards (issues) do GitLab; listar labels e membros | `issue-manager` | `skills/issue-manager/SKILL.md` |
| Criar ou conferir o índice de relatórios de uma sprint | `report-index` | `skills/report-index/SKILL.md` |
| Preparar a branch limpa (sem material de IA) que vai para a `main` | `repo-snapshot` | `skills/repo-snapshot/SKILL.md` |

## Ao adicionar uma skill

1. Crie a pasta em `skills/<nome>/` com o `skill-creator`.
2. Adicione uma linha nesta tabela: a tarefa em linguagem do grupo, o nome e o caminho.
3. Se a skill substituir outra, remova a linha antiga no mesmo commit.

Prefira skills por fluxo de trabalho (ex.: `teste-conectividade`), não por microsseção da documentação.
